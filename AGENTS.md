# AGENTS.md

## Stack

- **Next.js 16** (App Router, `src/app/`) — has breaking changes from earlier versions. Read `node_modules/next/dist/docs/` before writing code.
- **Payload CMS 3.84** — headless CMS with **PostgreSQL** (Supabase) via `@payloadcms/db-postgres`. Admin at `(payload)/admin/`.
- **Tailwind CSS v4** — PostCSS via `@tailwindcss/postcss`. No `tailwind.config.*` file; theme in `src/app/globals.css`.
- **Biome 2.4** — linter and formatter (NOT ESLint/Prettier). All formatting goes through Biome.
- **TypeScript 5** — strict mode. Path aliases: `@/*` → `./src/*`, `@payload-config` → `./src/payload.config.ts`.
- **pnpm** — package manager. Uses `pnpm-lock.yaml`.
- **Supabase** — PostgreSQL database + S3-compatible storage for media files.

## Commands

```bash
pnpm dev            # Start dev server (Next.js)
pnpm build          # Production build
pnpm lint           # Biome check --write (lint + auto-fix)
pnpm format         # Biome format (same as lint in this repo)
pnpm start          # Run production build

pnpm generate:types      # Regenerate Payload types (payload-types.ts)
pnpm generate:importmap  # Regenerate Payload importmap

pnpm seed           # Seed database with test data (node --env-file=.env scripts/seed.mjs)
```

After changing Payload collections, always run `pnpm generate:types` and `pnpm generate:importmap`.

## Project Structure

```
src/
  app/
    (frontend)/     # Public routes (layout.tsx, page.tsx, globals.css)
    (payload)/      # Payload admin + API routes (auto-generated, don't edit)
  collections/      # Payload CMS collections (Projects, Services, Media, etc.)
  globals/          # Payload CMS globals (Contact)
  modules/          # Feature modules per page (home, contacto, cotizador, etc.)
  shared/
    components/
      layout/       # Navbar, Footer
      providers/    # Theme provider, etc.
      ui/           # shadcn components (base-nova style)
    config/         # Routes, env, metadata, constants
    data/           # Static/seed data
    hooks/          # Shared React hooks
    lib/            # Utilities (cn, routes helpers)
    types/          # Shared TypeScript types
```

## Conventions

- **Locale**: Spanish-language content site (JP3D company). Route names and CMS content are in Spanish.
- **shadcn**: Components are `base-nova` style with `lucide` icons. Add new components via `pnpx shadcn@latest add <component>`.
- **Routes**: All route definitions live in `src/shared/config/routes.ts`. Use the route helpers (not hardcoded strings).
- **Modules**: Each page has a corresponding module in `src/modules/<name>/`. Page files in `(frontend)` are thin wrappers that render module components.
- **Biome rules**: `noUnusedVariables` and `noUnusedImports` are errors. `useSortedClasses` warns on unsorted Tailwind classes. `useImportType` enforced.
- **Email**: Resend SDK for transactional email (quote notifications). No SMTP/Mailpit needed.

## Gotchas

- `NODE_OPTIONS=--no-deprecation` is set on all scripts via `cross-env` — don't suppress it elsewhere.
- `pnpm-workspace.yaml` exists but this is a single-package repo (not a monorepo). The workspace config is only for build dependency management.
- Payload types file (`src/payload-types.ts`) is generated — never edit manually.
- `(payload)` route group is auto-generated by Payload — don't modify files there.
- No test framework is set up. There are no test scripts or test files.

## CI/CD

- **Platform**: Vercel (auto-deploys from GitHub)
- **Database**: Supabase PostgreSQL (pooler mode, port 6543)
- **Storage**: Supabase Storage (S3-compatible) for media files
- No CI runs on PRs or branch pushes — lint locally with `pnpm lint` before pushing.
